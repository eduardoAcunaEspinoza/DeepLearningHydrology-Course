# DeepLearningHydrology-Course

Welcome to the companion repository for the Deep Learning in Hydrology course. This workshop provides hands-on tutorials for modeling rainfall-runoff processes using Long-Short Term memory networks.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/eduardoAcunaEspinoza/DeepLearningHydrology-Course/blob/main/notebooks/LSTM_RainfallRunoff.ipynb)

## Course Overview

This course utilizes **Hy²DL**, a Python library designed to create hydrological models using advanced deep learning methods. Through these interactive notebooks, participants will learn how to:
* **Process large-sample datasets:** Work with standard hydrological data (e.g., CAMELS or CARAVAN).
* **Train Long Short-Term Memory (LSTM) models:** Configure and execute neural networks for runoff prediction.
* **Evaluate performance:** Analyze hydrological signatures and assess model accuracy.

## How to Use This Material

You do not need to install anything on your local computer to participate in this course. All exercises are designed to run entirely in the cloud via Google Colab.
* **Launch the Environment:** Click the "Open in Colab" badge at the top of this page to start the interactive session.
* **Save Your Work:** Once Colab opens, immediately go to `File > Save a copy in Drive` to keep your own editable version of the notebook.
* **Run the Setup:** The first cell in the notebook will automatically download the datasets and install the core `Hy2DL` library.
